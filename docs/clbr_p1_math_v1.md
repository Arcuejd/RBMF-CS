# CLBR-Gaussian-v1 数学说明

在既有训练尺度下 x=(T−C_m−μ)/s，LF亦相同。s>0，物理均值=C_m+μ+s×模型均值，方差乘s²，半宽乘s。这里的仿射是在共同异常单位上a+b l；不暗指绝对温度统一截距。

## 训练侧经验参数

对当前折T个配对月，最小化Σ_tΣ_i w_i(x_ti−a−b l_ti)²，月等权、Σw=1。LF常量/秩亏时显式使用b=0、a=加权HF均值并记录，不放大病态斜率。残差r_t=x_t−a−b l_t，固定欧氏正交POD矩阵B，z_t=Bᵀr_t。m=mean(z_t)，c=Σ||z_t−m||²/[K(T−1)]，d=mean_t Σ_i w_i(r_t−Bz_t)_i²。c,d仅加1e−8模型方差数值下限，不是物理已知噪声；d包含未解释的基底外均值差异。各向同性和独立场差异是简化假设，非真实海洋空间独立声明。

## 归一化生成模型

给定校准器、B、m,c,d和候选倍数g：

z ~ N(m,g c I_K)，e ~ N(0,d I_N)，x=a+b l+Bz+e，y=Cx+ε，ε~N(0,σ² I_p)。

所有Normal密度含(2π)与行列式归一化；没有N维“残差观测为零”辅助似然。令u=a+b l+Bm，Kx=g c BBᵀ+dI，S=C Kx Cᵀ+σ²I，r=y−Cu，则

E[x|y]=u+Kx CᵀS⁻¹r；Cov(x|y)=Kx−Kx CᵀS⁻¹C Kx。

E[z|y]=m+g c BᵀCᵀS⁻¹r；Cov(z|y)=g c I−(g c)² BᵀCᵀS⁻¹CB。

e与z在后验相关，场方差必须用整体Kx式，不能直接把系数后验方差加先验d而忽略交叉项。评分域永不观测，那里e与已观测e独立，得到diag(B Cov(z|y) Bᵀ)+d；重复观测同节点则C Cᵀ非单位，使用完整S。

在线σ²通过正规边际log p(y)=−[p log(2π)+logdetS+rᵀS⁻¹r]/2的有界经验Bayes选择；输入只有当前y、l及训练侧参数，不能读取目标HF、未来噪声或模拟器σ。它与d/低秩差异混淆、可能取边界，不能宣称估计的是独立校准的真实仪器噪声。条件协方差不传播该估计的不确定性。无有效观测返回u和Kx，不用零方差奇异似然；噪声未识别时明确记状态。NaN观测删除，Inf拒绝，索引非法/重复处理有测试，LF缺测拒绝、不擅自填充。

## 确定性参照

R=d C Cᵀ+σ² I。最小化0.5(y−C(a+b l)−CBz)ᵀR⁻¹(y−C(a+b l)−CBz)+||z−m||²/(2gc)。用独立增广最小二乘求解，在未观测评分点x=a+b l+Bz；因此与Bayes后验均值一致。已观测点还需e的条件均值。代码的确定性输出只用于未观测评分点的一致性检查，不把相同点收益重复归功贝叶斯。Bayes贡献是正规生成分布和条件不确定性，不是额外点精度。

## 区间与遗漏

条件潜在IAP场区间为μ±Φ⁻¹((1+q)/2)√V；同一场新的独立传感器观测区间为μ±z√(V+σ²)。后者与已有ε独立，但共享潜在场；不是另一个独立月份。B固定、校准a/b与m/c/d为点估计。校准参数、经验超参数、基底学习和真实参考误差未积分，因此这是条件模型后验，不称完整贝叶斯不确定性。

独立于外层评价的内层误差分位数分别校准潜在场和未来模拟观测半宽。尺度依赖候选完整拟合，已含所有遗漏误差及相关性的经验后果，不再把校准/基底单项方差无条件叠加。没有声称识别这些成分，也不声称时空交换性或有限样本覆盖定理。原后验和经验区间必须单列，失败可不同。

本模型有解析条件推断，不使用VB，不需要或沿用原ELBO。参考测试采用独立增广SVD、归一化联合/条件Gaussian密度恒等式、一维积分及后验抽样；用合成控制验证LF无增益、零观测、缺测、强先验和新增观测响应。所有模拟测试与真实开发数据分开。
