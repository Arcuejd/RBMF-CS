# P0 数学与实现边界

原 `model.py` 与历史冻结源码 SHA256 一致，未改写原算法。`DiagnosticRBMF` 继承原坐标更新，只记录每个完整 sweep 的因子和 ELBO。逐元素完整因子停止沿用原有 `convergence='factors'`：均值、完整协方差、Gamma shape/rate、rho均值/方差最大相对变化小于1e-6。它是停止规则的最小数值修正，不是精度改善承诺。默认ELBO停止和此规则分别报告，不能声称二者等价。

## 原始条件更新与同步诊断

P = diag(Eγ) + Eτδ ΨᵀΨ + Eτ Hᵀdiag(Eλ)H。
r_obs = Eτ Hᵀdiag(Eλ)y，r_LF = Eτδ Eρ Ψᵀl。
Σ=P⁻¹，μ=Σ(r_obs+r_LF)。诊断保存三个精度矩阵的特征值和沿每条观测基底行的Rayleigh商；比较Σr_obs与Σr_LF的面积RMS及二者夹角，不从迹比独自推断因果。

原更新顺序中最后的γ/τ/ρ/τδ晚于α更新，故落盘Σ与末轮精度不完全同步。诊断另外按最后因子求同步Σ并报告均值残差。有效自由度 tr(ΣP_obs)是冻结超参数的局部Gaussian响应，**不是**完整非线性VB估计器的广义自由度。完整重拟合响应另将第一个观测增加0.02℃，重新拟合所有因子。

## 条件已知噪声对照（不能直接部署）

只将τ设为正的常数τ0，其他条件模型相同：y_i|α,λ_i ~ N(h_iᵀα,(τ0 λ_i)⁻¹)，λ_i~Gamma(ν/2,ν/2)。ν=3，假定物理边际标准差σ=0.02℃时，τ0=s²ν/[σ²(ν−2)]。s=0.47136164192933816℃，τ0≈1666.36348。Gaussian生成器与Student-t似然分布不同，此对照只匹配边际方差。

q(α)中的Eτ替换为τ0；q(λ_i) shape=(ν+1)/2，rate=(ν+τ0 ξ_i)/2；删除q(τ)更新。实际独立子类在ELBO入口覆盖临时自由τ更新（该临时值尚未被其他因子使用），因此下一轮α/λ使用常量。ELBO观测项为Σ_i[logτ0+Elogλ_i−log(2π)−τ0 Eλ_i ξ_i]/2，删除τ先验与q(τ)熵；其余项保持原式。FixedPrecision的shape/rate仅用于固定长度的停止向量，绝非Gamma分布参数。边际预测噪声方差为ν/[(ν−2)τ0]，不沿用自由Gamma积分公式。

clean中σ仍取0.02℃作为假定正下限，是失配敏感性对照，不叫“已知clean方差”。固定噪声不能避免POD截断/位置代表性误差，不可从模拟噪声推断真实传感器总误差。

## ARD单项

只改变Gamma先验rate bγ:0.01→1，aγ不变。q(γ_k) rate=bγ+(μ_k²+Σ_kk)/2；ELBO采用对应的aγ log bγ−logΓ(aγ)+(aγ−1)Elogγ−bγEγ及原熵。实现由原VBConfig贯穿更新/ELBO，没有另加经验权重。该值是有限机制敏感性，不是经过充分验证的训练先验，更不因预测活跃就自动被接受。

## POD离线下界

固定秩r，在同一未采样评价格点上用真值求加权最小二乘min_a ||W_e^(1/2)(Ψ_e a−x_e)||。这是评价格点可达误差下界，不可部署。评价格点仅66个，r=70时下界可以为零，不能解释为70个模态可由12个观测精确恢复；不据此选秩。训练工件和基底70列均保持不变。

## 独立验证

`tests/test_p0_research.py` 比较新增记录器与原估计器逐位结果；固定精度ELBO用80,000次独立scipy归一化log-density积分检验，后验均值用增广最小二乘检验。另检查零/无穷精度拒绝、非空测试数组注入拒绝以及测试日期伪装为验证期拒绝。
