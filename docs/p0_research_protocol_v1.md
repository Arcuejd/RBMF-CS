# P0 机制诊断与未暴露数据准备预注册（2026-10-12）

本文件先于本轮候选性能计算写入。历史源码、数据、结果不改写。

P0—1 只读原 2000–2012 工件与 2013 全年输入。先固定最早/年中两月（1、7月）、种子1001、预算4/6/8/10/12做计时与机制试验；允许随后在小规模资源范围内完成12月单种子验证。扩大到多种子批量之前请求资源确认。clean和Gaussian 0.02℃分开，诊断先用Gaussian以复用历史验证设计。主指标为先逐月逐预算计算面积RMSE，再对月份、预算等权平均；MAE、逐月变化和收敛率同时报告。失败/非收敛不得从候选选择中删除：任一失败则不可选。平局取改动最少者。

有限对照：原配置、全部因子停止、高噪声精度初始化、较弱ARD先验（仅改b_gamma）、删除LF兼容、固定已知非零噪声精度（仅条件诊断）。不得将已知模拟噪声作为真实部署信息。Student-t尺度平方=边际方差*(ν−2)/ν，标准化后再除scale_c²；clean不采用零方差。仅在单机制证据支持后提出候选修正，不自动组合或无限搜索。固定精度对照单独修改ELBO；原模型保留。

记录全因子轨迹、ELBO、精度谱与观测方向的Rayleigh商、两类右端及经协方差映射后的贡献、冻结因子有效自由度、完全重拟合的扰动响应、新增观测响应、无在线观测和气候态基线。POD误差使用评价域加权最小二乘真值投影，明确为离线诊断下界，不参与选秩。

尚未获确认的实际意义提议：全年RMSE相对气候态改善≥5%、≥8/12月改善、12相对4节点改善≥2%。在用户确认前仅报告效应量，不宣布成功。2013全部证据属于开发验证。
