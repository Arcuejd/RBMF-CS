# 有限结构诊断结论（2026-10-13）

本轮已按预设停止条件结束。唯一新增候选——联合高斯q(α,ρ)——没有解决实际数据中的收缩，**不提升为正式改进方法，不继续扩展RBMF搜索**。后续主工作基线冻结为POD-Ridge，保留POD-LASSO和Gaussian-SBL对照。所有结论来自训练构造及2013开发验证，独立测试继续封存。

## 做了什么，以及停止条件

先写`p0_structure_protocol_v1.md`，仅检验两个问题：α与ρ的均场分解是否是主要瓶颈；原辅助兼容目标在不使用该分解时是否也会偏向小ρ。只增加联合推断一个候选，先验、训练工件、秩32和数据不变。默认初始化与上一轮已用的另一初始化组成有限2×2对照；每个推断族从两个收敛起点按最高ELBO选解，选择过程不读取真值误差。两起点全部保存。

接受门槛仍为clean/Gaussian均满足：相对气候态平均RMSE至少下降5%、至少8/12月改善、12相对4节点至少下降2%，所选结果全部收敛，并报告完整重拟合观测响应及强基线差距。失败则不增加新先验、秩、噪声权重、固定rho或结构组合。

## 更清楚的机制证据

**原目标确实自带压低ρ的效应，不完全是均场造成的。** 在固定γ、δ且没有在线观测的条件下，解析积分α后，ρ新增精度

`Q = δ lᵀl − δ²(Ψᵀl)ᵀ(Γ+δΨᵀΨ)⁻¹(Ψᵀl)`。

当Ψ正交且Γ=gI时，这等于`δ||l⊥||² + δg/(g+δ)||Ψᵀl||²`，两项均非负，后验ρ均值为`κρ0/(κ+Q)`。这里没有任何α–ρ均场近似。对2013的LF、固定γ=δ=κ=ρ0=1计算，ρ均值为0.001035–0.002728；这是条件机制诊断，不是原完整模型后验的替代。

这个结果解释了为什么POD子空间之外的LF分量，以及系数的零均值ARD先验，会通过辅助“残差为零”似然偏好小ρ。它不是发现原代码漏写公式，也不能据此断言所有多保真模型都有此问题。当前原模型可以作为一个数学一致的增广模型，但它的目标在本任务上不利于使用在线信息。

**联合因子确实改善了近似，却几乎没改善实际重构。** 联合模型正确加入Cov(α,ρ)，同时修改兼容残差期望与联合Gaussian熵。2013同一增广目标下，联合因子选中解比均场选中解ELBO高0.12879–0.19303，平均0.15105；但误差下降只有数十微℃。两种初始化在真实2013预测上的最大逐点差不到9e-8℃，没有得到有意义的不同解。

不能据此排除所有均场限制：联合候选仍把γ、τ、τδ、λ与(α,ρ)分开。可以排除的是“只补α–ρ相关性就能主要解决本次问题”这一具体假设。
