# 真实极地数据部署实验（首轮）

已执行2014年1、4、7、10月，北大西洋侧70–80°N、20°W–20°E，50 m月平均原位温度；每月346个共同有效格点。训练气候态、尺度、70个POD模态与协方差来自2000–2012，2014全年未参与拟合；2013验证集保留，本次没有调参。

每种方法使用4个相同初始节点，逐次部署至12个传感器。MC-EIR、一次随机选点、均匀覆盖（在可行候选中选择离已选点最远的位置）共12组实验，108次变分推断全部收敛，所有部署通过相同工程情景约束。

## 实际结果

下表为三种方法共同未观测区域的面积加权RMSE（℃）。评估时排除三种部署的传感器并集，对所有方法使用相同格点及cos(纬度)权重。该区域是实验评估区域，不用于训练、选点或拟合。各方法自身未观测区域的逐轮指标另存于metrics.csv，不宜把不同评估域的细微差异作为方法优势。

4、7、10月重构优于仅ORAS5，1月更差。三种选点方法的共同域误差非常接近，当前设置不能证明MC-EIR部署优于随机或均匀覆盖。随机只运行一次，未构成统计比较；不能根据2014测试结果调整参数后继续将其作为无偏测试。

## 情景假设

- 观测由选中IAP格点值模拟，加入标准差0.02 ℃的高斯噪声；同月所有方法使用同一个按节点固定的噪声实现。规划器只接收选点后获取的观测，不接收测试真值或未来噪声。
- 网关假定为75°N、0°E，通信半径250 km；海冰浓度上限0.6。初始节点按网关距离及海冰可行性选择，不根据温度选择。
- 任务1小时、12个传感器、网络能量预算1000000 J；功率、发包、传输和成本参数均为声明的情景假设，未根据真实硬件标定。当前模型不含接收/空闲无线电能耗。
- ORAS5为独立来源的LF候选，IAP为格点HF候选。温度场真实，但观测和部署是数值实验，未使用Argo/ITP作为独立现场验证；原产品同化独立性未证实。

## 在VS Code中重跑

打开项目后按Ctrl+Shift+B，选择“真实极地数据：部署训练与评估”。运行配置为configs/polar_deployment.json；.vscode/tasks.json使用项目虚拟环境。

也可在项目终端运行：

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
.venv\Scripts\python scripts/run_polar_deployment.py
.venv\Scripts\python scripts/check_polar_deployment.py
```

结果保存在D:\project\RBMF-CS\outputs\polar_deployment：index.html为地图和曲线，summary.json为同域比较及参数出处，metrics.csv为逐轮指标，progress.log为运行日志，verification.json为落盘复核结果。每个月/方法子目录保存逐轮后验、推断诊断、部署决策及最终物理温度场。HTML可在浏览器中打开，地图为经纬度格点图，不含海岸线。
