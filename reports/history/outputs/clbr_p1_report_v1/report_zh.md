# P1—3 / P1—4 有限研究交付报告（2026-10-13）

本轮已完成新模型CLBR-Gaussian-v1、数学说明、参考测试、按连续季度嵌套的2013全年有限实验和独立核验。**点预测与不确定性均未达到预设完整验收门槛，停止本轮候选扩展，不提升CLBR为正式改进方法。继续保留POD-Ridge为主基线。** 这是一份可复现的部分改善与负结果报告，不是独立泛化结论。

## 1. 研究边界与数据依据

没有继续搜索原RBMF先验或变分族；CLBR是独立命名的正规生成模型，不是原实现修复，也未沿用原ELBO。未修改部署评分、增加盐度、开展污染扩展或非共轭归一化先验研究。原算法、训练工件和历史结果不覆盖。

已核查当前开发输入：2000–2012年有156个月HF及固定气候态、尺度、POD，缺少对应训练期LF；只有2013全年具有当前已审计配对HF/LF。未从HF合成LF，未自动下载。沿用346格点、50m月均原位温度、HF训练月气候态，s=0.47136164192933816℃。ORAS5位温以同月盐度和TEOS-10转换并插值，IAP异常按历史核验偏移恢复；月均非线性转换及产品精度/同化依赖限制仍在。

外层四个连续季度留出：9个月学习、3个月评价；内层在外层允许的三个季度间轮流留出：6个月学习、3个月选择/校准。所有同月格点、预算、种子在同一时间折。2000–2012工件保持训练用途；2014不参与本轮；2015+封存温度场未读取或评价。2013已反复用于路线开发，分块不能消除路线选择的开发偏差。

## 2. 新模型与有限候选

全域仿射a+b LF只有两个参数；残差系数先验N(m,g c I)正规归一化，m/c由当前训练侧POD投影估计，场差异e~N(0,dI)，观测噪声ε~N(0,σ²I)。x=a+b LF+Bz+e，y=Cx+ε。联合条件更新包含系数和场差异之间的后验相关性，没有全网格残差为零的辅助似然。固定16阶POD，g仅0.5/1/2三个候选，不加季节项或新基底。

σ仅用当前获取的观测最大化正规边际似然，标准差边界0.001–1℃。它没有读取模拟器0.02℃；边界是数值建模假设，不是仪器规格。条件后验不传播仿射校准、经验超参数或基底学习不确定性。经验区间使用外层训练侧的内层留出残差分位数，综合反映遗漏误差，不再独立叠加校准/基底方差。

严格折外Ridge只有6候选：秩8/16×λ=0.001/0.01/0.1。历史冻结Ridge/LASSO/SBL/RBMF作为已在2013全年选参的参照，另列信息条件。本轮四个外层折均选g=2、Ridge秩16和λ=0.01。因此严格折外Ridge最终预测恰与冻结Ridge一致；这不改变历史参照曾暴露的事实。g选中预设上界只记录为现象，不据此扩大范围。

四个外层仿射斜率依次0.3100、0.2639、0.3049、0.1576；截距为模型单位0.2289、0.1508、0.1057、0.1758。完整内层候选、校准参数、允许月份和区间分位数见[折清单](../clbr_p1_full_v1/fold_manifest.json)。仿射斜率有跨折差异，但不能仅凭四折证明季节模型有效。

## 4. LF与在线观测分别贡献了什么

仅仿射LF的RMSE为0.438377℃，无在线观测CLBR为0.438291℃，删除LF均值的无观测预测为0.443130℃。在无观测条件下，LF均值具有有限正贡献；但有观测后完整CLBR的Gaussian RMSE比匹配消融高约0.491%，仅5/12月优于消融，**本轮未证实LF带来额外在线点预测增益**。不能简化为“LF在任何情况下都无信息”。

该消融继承完整模型残差均值、方差和选中g，按相同在线噪声规则重估σ，不另调参。其残差统计仍由带LF的训练校准产生，不是独立优化的纯HF模型；公平无LF参照是另行内层选择的Ridge。不能事后把消融改为新的获胜候选。

Gaussian 12节点时，完整CLBR相对自身无观测预测的场RMS变化约0.19353℃；从10增至12节点变化约0.05998℃；首观测增加0.02℃后完整重拟合的场RMS变化平均约0.001584℃（12个月、seed1001）。在线贡献已明显存在，但响应增强不等于超过Ridge。

冻结噪声/先验条件下，Gaussian 12节点的系数有效自由度约6.369；保存诊断中的总潜在场观测自由度约11.443，还包括观测点的独立场差异，不能与原RBMF系数自由度不加区分地比较。噪声标准差均值约0.04051℃，36个案例中30个落在0.001℃下界；clean也有30/36落下界。这说明测量噪声与表示差异的辨识仍弱，不支持把估计σ解释成已验证的真实仪器噪声。

Bayes与确定性残差Ridge在固定未观测评分域的最大逐点差仅2.31e−15℃，符合解析同均值关系。点预测收益来自校准均值/残差模型及在线更新，不重复归功贝叶斯；Bayes提供正规条件分布和后验协方差。

经验校准相对原条件后验有所改善，但不能仅以“95%覆盖接近95%”写成可信不确定性全面成功。经验分位数来自外层允许月份的内层留出误差，与内层选参共享数据，仍有选择偏差；仅一年且存在时空相关，不声称conformal有限样本保证。未将校准器/基底不确定性显式积分，经验校准只反映遗漏误差的总后果。

## 6. 测试、修复、隔离与资源

用户运行95项测试，全部通过、无跳过，包含独立增广SVD、归一化Gaussian密度恒等式、一维积分、区间抽样、单位、缺测/重复观测、仿射合成控制、折污染、I/O门禁及原项目回归。助手本轮只读取和汇总保存结果，没有代跑模型实验。

首轮94项测试通过但指标独立核验失败；原因是核验器float32权重累加与实验端float64归约不一致。一次修复显式提升核验累加精度并增加回归测试，保留v1失败。模型、候选、门槛均不改变，未放宽核验容差。用户重跑v2后核验通过，再批准全年。

全年独立核验通过3600条外层点预测、9720条内层候选评分、8640条区间记录；失败0。检查包含折/选参/区间尺度来源、配对节点与观测、独立未来噪声、确定性/Bayes同均值和保存指标重算。原model.py、训练工件和历史选参哈希不变，封存manifest未变且release_authorized=false；I/O门禁为进程内工作流保护，不冒充OS安全沙箱。

全年单进程单线程62.617秒，峰值123,117,568字节（约117.4MiB），实验输出109,634,362字节（约104.6MiB）。符合用户批准300秒检查点与500MiB磁盘上限；内存仅测量，没有OS硬限。work_units=11928是程序计数的主要求解调用，不等于独立环境或包含全部辅助运算的总拟合数。

四个外层折各选3个CLBR候选和6个Ridge候选，没有新增候选。全年使用更多预算/种子后，第一折Ridge选参从pilot的秩8变为16是预先规定内层目标的结果，不是读取外层误差后换参。未把小试结论作为候选扩展依据。

## 7. 停止决定与后续边界

P1—3：新模型已实现、有在线响应、优于气候态，但未超过主强基线；不提升CLBR。LF在线额外贡献未获支持。P1—4：经验校准改善覆盖与部分评分，但未满足完整规则；不认定可信区间研究已验收成功。按有限协议停止，不增加先验尺度、季节项、秩或新的模型组合。

保留既有冻结POD-Ridge（16阶、λ=0.01）为后续点预测主基线，保留LASSO/SBL与原RBMF比较。当前不为CLBR拟合一个最终全2013模型以准备独立测试，也不把匹配无LF消融事后提升为新路线。Ridge常宽区间在本轮作为可解释参照；没有按测试年份重新校准或宣称真实观测覆盖保证。

独立测试仍需补齐合格ORAS5/海冰、IAP基准版本及来源/QC审计；已封存候选不因本报告获得开放资格。若未来开展独立评价，应先完成数据资格、最终方法/参数/区间校准规则冻结和明确释放授权。本轮没有打开独立测试性能，也不作顶刊水平承诺。
