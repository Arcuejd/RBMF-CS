# 联合因子与结构积分说明

原增广目标p(y,aux=0,α,ρ,γ,λ,τ,τδ|l)保持不变；本轮只改变变分族为q(α,ρ)q(γ)q(λ)q(τ)q(τδ)。均值m=(μα,mρ)，协方差C分块为Cαα、cαρ、Cρρ。G=ΨᵀΨ，v=Ψᵀl，L=lᵀl，D=Eτδ，T=Eτ。

联合高斯精度为

```
B = [ diag(Eγ)+DG+T Hᵀdiag(Eλ)H   -Dv ]
    [ -Dvᵀ                        κ+DL ]
b = [ T Hᵀdiag(Eλ)y ; κρ0 ]
C = B⁻¹, m = Cb.
```

qγ、qλ、qτ仍使用α的边际二阶矩；qτδ的shape=aδ+N/2，rate=bδ+ξδ/2，其中

ξδ=||Ψμα−mρl||²+tr(GCαα)+L Cρρ−2vᵀcαρ。

最后一项不可遗漏。联合更新顺序：(α,ρ)→γ→λ→τ→τδ。ELBO中α和ρ的独立先验期望不变，compatibility期望加入D vᵀcαρ，Gaussian熵由H(qα)+H(qρ)替换为H(q(α,ρ))。相对原边际形式ELBO的额外熵项是[logdet C−logdet Cαα−log Cρρ]/2。完整停止向量包含cαρ；ELBO不下降和局部收敛不保证全局最优。旧源码和模型不修改。

## 目标本身的解析检验

条件固定γ、δ>0，无在线观测。A=Γ+δG，积分α后，原compatibility伪观测给ρ新增精度

Q=δL−δ²vᵀA⁻¹v ≥0。

因此ρ后验均值=κρ0/(κ+Q)，方差=1/(κ+Q)，**没有任何均场近似**。若基底正交且γ=gI，l=Ψu+l⊥，则Q=δ||l⊥||²+[δg/(g+δ)]||u||²。POD截断的正交补与ARD都能产生这项收缩。有限正精度下这不是代码bug，而是将N维兼容关系作为观测到零的辅助似然的后果。

将N维兼容因子乘α的ARD先验后，对α的积分是Z(γ,δ,ρ,l)，它依赖超参数和ρ，并非恒定。若另定义归一化条件先验p(α|γ,δ,ρ,l)∝p(α|γ)×compatibility/Z，模型会改变，γ/δ/ρ的原共轭更新和原ELBO都不再适用。本轮只写出这一差异，不用删除Z或随意降似然权重伪装成实现修复，也不跨模型比较ELBO数值。

## 条件低维积分

K=1，Gaussian τ固定、λ=1；γ、δ仍沿原Gamma超先验积分。未归一化二维后验为

```
p(a,r|y,aux=0,τ) ∝ exp[-τ||y-ha||²/2 - κ(r-ρ0)²/2]
                  × (bγ+a²/2)^[-(aγ+1/2)]
                  × (bδ+||ψa-rl||²/2)^[-(aδ+N/2)].
```

代码保留所有正态与Gamma归一化常数以计算该条件模型log evidence；MF/联合ELBO应不高于该值（在积分精度容差内）。用Gauss-Legendre二维积分并做节点与边界检查；γ/δ已解析积分，不是固定超参数MAP。此参考仍条件于已知Gaussian噪声，不能等同完整Student-t未知噪声实数问题的精确后验。报告该适用边界，不从玩具例子推断真实全维全局结论。
